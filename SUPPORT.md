# Поддержка

## Где задать вопрос

- Ошибка с воспроизводимым сценарием — bug report в GitHub Issues.
- Предложение поведения или API — feature request в GitHub Issues.
- Уязвимость — только по инструкции из [SECURITY.md](SECURITY.md).
- Общие вопросы по Yandex AI Studio — в официальных каналах поддержки Yandex
  Cloud, если вопрос не относится к коду проекта.

Проект развивается участниками сообщества и не предоставляет гарантированного
SLA. Чтобы получить ответ быстрее, приложите версию, окружение, минимальный
пример и очищенные от секретов логи.
