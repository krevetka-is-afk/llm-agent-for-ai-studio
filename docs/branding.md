# Бренд и внешняя атрибуция

Этот документ отделяет техническое именование проекта от заявлений о бренде и
партнёрстве. Он не заменяет юридическое согласование.

## Имена проекта

- Публичное имя: **Shada Agent Builder for Yandex AI Studio**.
- Короткое имя: **Shada Agent Builder** или **Shada** после первого упоминания.
- Python distribution: `llm-agent-for-ai-studio` — сохраняется для совместимости
  до отдельного решения о миграции.
- Import package: `ai_studio_agent_builder` — не переименовывается без плана
  обратной совместимости.

> базе Yandex AI Studio.

официальный статус или endorsement.

## Партнёрская формулировка

Текст о партнёрстве, порядок упоминания сторон, логотипы, цвета и ссылки должны
быть письменно согласованы правообладателями до изменения видимости репозитория.
Согласованная формулировка заменяет этот раздел и добавляется в README, описание
репозитория и release notes одним атомарным изменением.

До согласования нельзя использовать формулировки «официальный инструмент
Yandex», «разработано Yandex», «Yandex рекомендует» или иные утверждения,
которые могут быть восприняты как endorsement. Нельзя брать логотипы из поиска
или публичных страниц без подтверждённых правил использования.
